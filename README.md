# Impasto di Larsen

Landing page local para a marca Impasto di Larsen, com foco em experiências de pizza napoletana para eventos e pizzas artesanais pré-assadas congeladas.

## Executar

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Estrutura

- `index.html`: conteúdo semântico, SEO básico e seções da landing page.
- `styles.css`: direção visual responsiva em preto, marfim e dourado envelhecido.
- `script.js`: menu mobile, feedback do formulário e animações de entrada.
- `assets/`: logo enviada e imagens gastronômicas usadas na composição.
